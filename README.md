# Ras7rba

## الخريطة

هذا المستودع هو مستودع موحّد (monorepo) يضم:

- `algo-faqih/` — مشروع بحث شرعي خفيف مبني على SQLite FTS5
- `docs/THAWABIT.md` — ملف الفهرس الرسمي للثوابت والمنهج
- `CHARTER.md` — الميثاق الرسمي للمنهج والضوابط

## المعيار الأساسي

- `Issues` = مسودات ومناقشات تاريخية
- `Files` = المرجع المعتمد
- `README.md` = خريطة المشروع فقط
- `CHARTER.md` = الدستور
- `docs/THAWABIT.md` = معيار القبول والرفض

## الخلاصة الخماسية

- الثابت لا يُفرقع.
- المشتق لا يُقدس.
- العمل يثبت الباطن.
- المنهج يحدد القبول والرفض.
- اليقين يأتي بعد التمييز.
