# Ras7rba

## 📌 دستور المنهج والثوابت (CHARTER.md)

- الثابت لا يُفرقع: الوحي المعصوم، السنة الصحيحة، والفطرة العقلية خط أحمر ثابت لا يقبل التفكيك.  
- المشتق لا يُقدس: الاجتهادات، الروايات المتأخرة، والحلول التقنية تُخضع للتمحيص والفرز المستمر.  
- العمل يثبت الباطن: لا عبرة بالأوهام، الرموز، أو الادعاءات؛ العبرة بالصدق المنهجي والأثر النافع ماديّاً.  
- الضوابط الحاكمة: لا فتوى آلية، لا تسويق للغيب، ولا إلباس للتقنية بعباءة القداسة أو الرمزية.  
- التواضع المعرفي: اليقين والسكينة يأتيان بعد التمييز والتحقق، لا قبلهما. (التفاصيل في CHARTER.md).
